# Core Loop

## Moment-to-Moment Loop
1. reposition using movement/dash
2. threaten with normals or specials
3. spend resource for advantage
4. hit, block, or evade
5. capitalize with short follow-up or reset spacing

## Match Loop
1. round starts
2. players approach and test spacing
3. ability usage shifts positioning advantage
4. players trade offense/defense
5. one player is KO'd
6. round resets
7. repeat until match result

## Strategic Loop
- move to gain angle
- spend resource intentionally
- avoid overcommitting
- punish recovery and predictable options
