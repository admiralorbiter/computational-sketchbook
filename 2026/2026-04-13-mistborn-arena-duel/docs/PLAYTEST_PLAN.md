# Playtest Plan

## Purpose
Validate whether the game is fun before expanding content or networking.

## Questions to Answer
- does movement feel responsive?
- are both characters understandable?
- is blocking useful but not dominant?
- do specials feel worth their cost?
- is the match readable with placeholder visuals?

## Session Format
- 5 to 10 matches per tester pair
- short debrief after each set
- record issues in playtest notes

## Metrics to Observe
- repeated overpowered options
- confusing moves
- unused abilities
- frustrating movement states
- readability failures
