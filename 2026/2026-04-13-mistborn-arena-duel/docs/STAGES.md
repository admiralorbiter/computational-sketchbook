# Stages

## Stage 1 - Rooftops / Training Grounds Hybrid

### Goals
- readable layout
- supports mobility
- supports anchor point gameplay
- not too large

### Layout
- one main platform
- two slight side elevations or mini platforms
- open center space
- bounded left/right edges

### Interactive Elements
- 3 to 5 metal anchor points
- no lethal hazards initially

### Spawn Design
- symmetric spawn positions
- enough distance for round start readability

### Technical Notes
- stage collision should be simple and stable
- anchor points should be data-defined, not hardcoded into character logic
