# Characters

## Character A - Coinshot/Lurcher-Inspired Duelist

### Fantasy
Mobile skirmisher using metal interactions and projectiles.

### Role
- mobility-heavy
- spacing control
- setup play
- weaker direct brawling

### Base Attributes
- medium health
- high mobility
- medium-low raw damage
- stronger repositioning

### Core Moves
- light combo
- heavy push burst
- coin shot projectile
- push/pull movement special

### Design Notes
This character should reward players who use the stage and anchors intelligently.

## Character B - Windrunner-Inspired Vanguard

### Fantasy
Aerial control fighter using lashings and committed power strikes.

### Role
- midrange control
- better direct pressure
- easier to pick up
- less setup complexity

### Base Attributes
- slightly higher health
- medium mobility with burst aerial options
- stronger direct engagement

### Core Moves
- light strike string
- heavy pressure attack
- directional lashing burst
- slam / knock-up special

### Design Notes
This character should feel decisive and readable, not overly technical.
