# Definition of Done

## Ticket-Level Done
A task is done when:
- implementation works in dev build
- no known critical bug blocks its intended use
- debug output exists if needed for diagnosis
- relevant docs/data updated
- code is readable and consistent with project standards

## Feature-Level Done
A feature is done when:
- it works in the intended gameplay loop
- it can be tuned without invasive rewrites
- it survives round reset and repeat play
- it does not break both-player local control

## MVP Done
The MVP is done when:
- two players can complete multiple full matches locally
- both prototype characters are distinct and functional
- HUD and round flow work
- major debug tools exist
- the game is fun enough to justify polish or online expansion
