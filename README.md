# Computational Sketchbook

A consolidated repository for short-lived software probes, single-afternoon prototypes, agentic generation artifacts, and computational curiosities.

---

## The Philosophy of the Sketchbook

When modern AI copilots and autonomous agents collapsed the cost of turning an idea into running software, a GitHub repository ceased to be evidence of a durable, multi-year product. Frequently, a repository was simply a page in a sketchbook.

Rather than cluttering GitHub with hundreds of orphaned, single-commit standalone repositories, the **Computational Sketchbook** preserves the code, provenance, and lessons of these experiments in a structured, searchable home.

---

## Repository Structure

```text
computational-sketchbook/
├── README.md
├── CATALOG.md
└── <year>/
    └── <date>-<slug>/
        ├── README.md   # The idea, what was built, why it stopped
        ├── ORIGIN.md   # Original repository, commits, and SHAs
        └── src/        # Full original source code
```
