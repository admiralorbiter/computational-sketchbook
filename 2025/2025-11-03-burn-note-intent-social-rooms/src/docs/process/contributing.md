# Contributing

## Workflow
- Fork/branch: `feature/<slug>`
- Conventional commits (e.g., `feat: add whisper expiry field`)
- Small PRs; link to relevant ADRs and docs

## Dev Setup
- Rust stable; see repo `README.md` for commands
- Run API locally: `cargo run -p web`
- Tests: `cargo test --workspace`

## Docs Rules
- Keep docs concise and actionable
- Capture irreversible choices as ADRs in `docs/adr`
