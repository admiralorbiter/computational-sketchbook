# UX — Reporting & Moderation Tools (MVP)

## Reporting Flow
- Tap report on message → choose category → consent to include plaintext
- Submit → confirmation and muted view of reported content

## Moderator Tools
- Queue with categories; decision actions: tombstone, shadow-limit, ban session keys, slow-mode
- SLA targets: severe categories TTR < 30m

## Transparency
- Public aggregated counts; quarterly update
