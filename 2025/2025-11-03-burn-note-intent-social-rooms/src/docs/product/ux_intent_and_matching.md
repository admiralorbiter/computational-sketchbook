# UX — Intent Entry and Matching

## Context
Searchless by default: One-line intent → best room with visible but private cues.

## Screens & States
- Home: intent input, sensitive-topics toggle, language chip, voice input
- Preview card after ≥10 chars: top room, 2 highlights, vibe
- Join as read-only for first 60s (toggle)
- Alternates panel: 2–3 diverse rooms via MMR
- Fit meter (0–3 dots) and “Why you’re here” hint (local)

## Controls to Improve Fit
- Room switcher: show alternatives
- Feedback chips: Too broad / Wrong vibe / Off-topic / Sensitive content
- Vibe slider (experiment): chill ↔ debatey
- Negative keywords (advanced)

## Errors/Empty
- Network fail → retry with clear copy
- No good match → suggest facets and alternates
