# Burn Note — Documentation

This folder contains product, architecture, security, API, and runbook documentation for the Burn Note MVP.

## Structure
- product — PRD and UX specs
- architecture — high-level design and sequence diagrams
- algorithms — matching algorithms and scalable strategies
- adr — Architecture Decision Records
- api — API standards and contracts (names/semantics only for MVP)
- security — privacy caveats and threat model (MVP scope)
- process — contribution and collaboration docs
- runbooks — local dev and operational runbooks
- work — agent handoff tracking, sprint status, context summaries

## Start here
- product/prd_burn_note_mvp.md
- architecture/HLD.md

## Contributing to docs
- Keep documents concise and task-oriented; prefer links to repetition.
- Each doc begins with Context, Decisions, and Checklist (when relevant).
- Record major decisions as ADRs in docs/adr.
