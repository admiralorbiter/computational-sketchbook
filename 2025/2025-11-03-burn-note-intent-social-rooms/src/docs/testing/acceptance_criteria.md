# Acceptance Criteria (MVP)

## Core
- Submit intent → inside room ≤ 2.0s P50, ≤ 4.0s P95
- Join and post without account
- Clear privacy banner (plaintext MVP)

## Safety
- Reporting flow works end-to-end with consent copy
- Slow-mode and rate limits enforce caps

## UX
- Alternates panel offers 2–3 diverse options
- Read-only 60s mode available and visible
