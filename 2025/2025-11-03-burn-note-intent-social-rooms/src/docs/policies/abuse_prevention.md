# Abuse Prevention — Playbook (MVP)

## Controls
- Token budgets and quotas per action
- Content-free throttles: message size caps, media whitelist, cool-downs
- Circuit breakers on envelope volume per room
- Invite-only or moderated subrooms for targeted topics

## Response
- Detect spikes; enable slow-mode; freeze joins if needed
- Shadow-limit abusive sessions; escalate to bans
