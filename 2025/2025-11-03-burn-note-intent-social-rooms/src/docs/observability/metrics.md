# Metrics & SLOs (MVP)

## Health Metrics
- Join latency (P50/P95)
- Envelope throughput per room
- Error rates (4xx/5xx)

## Product Metrics (aggregated)
- Match Fit thumbs (rate)
- Time-to-first-reply (median)
- 7-day healthy return

## Security Metrics
- Moderation TTR by severity
- Rate limit trigger counts

## SLOs
- Join P50 ≤ 2.0s; P95 ≤ 4.0s
- Error rate < 1% sustained
