# ADR 0001 — Web SPA Only for MVP

## Status
Accepted (Nov 2025)

## Context
We need to move fast with a single client surface to validate product-market fit.

## Decision
Implement MVP as a Web SPA (desktop + mobile web) only.

## Consequences
- Faster iteration and simpler release pipeline
- Shared code for matching UX and room UI
- Native apps deferred to post-MVP parity plan
