# 15 — Glossary

- **Workspace** — isolated investigation context with its own data and saved view state.
- **Entity** — person, organization, place, or event record.
- **Relationship** — typed connection with role, dates, strength, confidence, and provenance.
- **Strength** — tie intensity (1–5), independent from evidence.
- **Confidence** — evidence trust (1–5), used by analysis weighting.
- **Provenance** — source data for a fact (title, URL, confidence, raw snapshot).
- **Enrichment** — pulling structured facts from Wikipedia/Wikidata with user review.
- **Power Path** — influence‑aware path minimizing a composite cost across edges/nodes.
- **FTS** — full‑text search (SQLite FTS5) used for names, descriptions, select metadata.
- **LOD** — level of detail strategy to optimize rendering at scale.
