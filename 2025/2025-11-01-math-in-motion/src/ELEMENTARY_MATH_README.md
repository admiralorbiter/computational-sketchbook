# Elementary Math Adventure - Grades 3-5

An interactive educational game designed specifically for elementary school students (Grades 3-5) to learn and practice fundamental math concepts through engaging visual activities.

## Features

### Grade 3 Standards
- **Multiplication Garden**: Visual multiplication with arrays and flowers
- **Fraction Pizza**: Understanding fractions as parts of a whole
- **Place Value Castle**: Building numbers with place value blocks

### Grade 4 Standards  
- **Decimal Diner**: Money math with decimal operations
- **Advanced Fractions**: Fraction equivalence and operations

### Grade 5 Standards
- **Volume Vault**: 3D volume calculations with interactive shapes

## How to Play

### Controls
- **TAB**: Switch between math scenes
- **H**: Toggle Math Helper (shows concepts and examples)
- **S**: Slow motion mode
- **P**: Pause/Resume
- **R**: Reset current scene

### Scene-Specific Controls

#### Multiplication Garden
- Type numbers to answer multiplication problems
- Visual arrays help understand multiplication as repeated addition

#### Fraction Pizza
- Click on pizza slices to select fractions
- See fractions on number lines
- Practice fraction equivalence

#### Place Value Castle
- Use arrow keys with number keys (1-4) to adjust place values
- Build target numbers with visual blocks

#### Decimal Diner
- Number keys 1-5: Add menu items
- Plus key (+): Add money
- Enter: Complete order and calculate change

#### Volume Vault
- Arrow keys: Adjust dimensions
- C: Switch between cube and rectangular prism
- Calculate volume to match target

## Educational Benefits

- **Visual Learning**: All concepts use colorful, interactive visuals
- **Immediate Feedback**: Students get instant feedback on their answers
- **Progressive Difficulty**: Problems adapt to student performance
- **Multiple Representations**: Concepts shown in different ways (visual, numerical, verbal)
- **Engaging Themes**: Each scene has a fun, child-friendly theme

## Technical Requirements

- Python 3.6+
- Pygame library
- Windows, Mac, or Linux

## Installation

1. Install Python 3.6 or higher
2. Install Pygame: `pip install pygame`
3. Run the game: `python elementary_math_adventure.py`

## Learning Objectives

### Grade 3
- Master multiplication facts within 12×12
- Understand fractions as numbers on number lines
- Use place value to round and perform operations within 1000
- Work with area, perimeter, and basic geometry

### Grade 4
- Perform multi-digit operations fluently
- Understand fraction equivalence and operations
- Work with decimals to hundredths
- Convert measurement units

### Grade 5
- Extend place value to thousandths
- Perform decimal operations
- Add/subtract fractions with unlike denominators
- Calculate volume and work with 3D shapes

## Teacher Notes

- Each scene can be used as a standalone activity or part of a lesson
- The Math Helper (H key) provides scaffolding for struggling students
- Slow motion mode helps students follow complex processes
- All scenes include visual representations to support different learning styles
- Scoring system provides motivation and tracks progress
