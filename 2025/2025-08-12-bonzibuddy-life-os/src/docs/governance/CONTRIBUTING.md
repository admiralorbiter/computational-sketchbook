# Contributing (solo‑friendly)

## Dev setup
- Python 3.11+
- `pip install -r requirements.txt`
- `pre-commit install`

## Style
- Black, isort, Flake8, mypy for Python
- Prettier, ESLint for JS/HTML
- Conventional commits optional: `feat:`, `fix:`, `docs:`

## Labels
- Priority: P0/P1/P2
- Size: S/M/L
- Type: feature/bug/chore/docs
- Domain: health/hobbies/research
