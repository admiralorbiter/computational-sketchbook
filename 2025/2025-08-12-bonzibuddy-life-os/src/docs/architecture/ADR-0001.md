# ADR-0001: v0 Technology & Process Choices
- **Status:** Accepted
- **Date:** 2025-08-12

## Context
We need a small, local, single‑user app that can grow. You prefer pip, SQLite, manual control of schema, and minimal JS.

## Decision
- pip + virtualenv
- Flask + Jinja + Bootstrap + Alpine.js
- SQLAlchemy ORM, **manual SQL migrations** (no Alembic)
- No scheduler in v0
- Single‑user, local‑first; no public API
- pytest + coverage, pre‑commit hooks
- ADRs per feature/bucket; Scrum-ish sprints; Starter Plan is source of truth

## Consequences
- Faster startup, fewer moving parts
- Manual migrations demand care; we add `schema_version` and tooling
- Future integrations (Oura, CGM) handled via importers first

## Alternatives considered
- Poetry + Alembic + HTMX: more ceremony than needed for v0
- React SPA: unnecessary complexity now
